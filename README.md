# Assignment Deadline Tracker

A web application that helps students organize assignments, monitor upcoming deadlines, and prioritize their workload.

## Features

- **Add Assignments:** Enter an assignment name, due date, and estimated hours remaining.
- **Dashboard:** View counts for upcoming, overdue, and high-risk assignments.
- **Upcoming Deadlines:** See assignments due within the next seven days.
- **Risk Levels:** Identify assignments as Low, Medium, High, or Overdue.
- **Countdowns:** See how many days remain until each deadline.
- **Delete Assignments:** Remove assignments that are no longer needed.
- **Persistent Storage:** Keep saved assignments after refreshing the browser using local storage.
- **Date Formatting:** Display due dates in a readable Month Day, Year format.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add an assignment to get started.
